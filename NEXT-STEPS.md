# Продолжение после просмотра 0.2.0

Сначала оценить реальные кадры из preview и обсудить желаемый стиль. APK ещё не собран; в README есть инструкция GitHub Actions.

Следующий этап:

1. Собрать APK и проверить на телефоне: запуск, полный экран, одновременное движение и обзор, редактор управления, сохранения.
2. Проверить подключение двух телефонов по Wi-Fi, получение наград и призыв в общей комнате. Сейчас награды и реликвии рассчитывает хозяин, профили гостей ещё упрощены.
3. По отзыву о кадрах доработать оружие, освещение, ландшафт, анимации и оформление меню.
4. Проверить сложность и темп прокачки: 7 боссов, уровни 2–14, рецепты реликвий, боеприпасы.
5. После этого расширять карту, способности, существ и боссов. Транспорт и полноценный API модов пока не реализованы.

Выполнено локально: 18 проверок логики и отрисовка настоящих GLSL/геометрии через Mesa EGL без GL-ошибок. Браузерные проверки, сборка Android и LAN-тест подготовлены в CI, но ещё не подтверждены запуском.
