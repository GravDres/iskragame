# После переделки 0.3

По просьбе пользователя выполнена основная переделка. Джойстик, независимые касания, контекстная кнопка, чувствительность, прокрутка и категории инвентаря, повторное использование моделей, отсечение камерой, порционная подготовка мира, внешний вид оружия, существ и боссов реализованы. Подробности — CHANGELOG.md и PERFORMANCE.md.

Проверены 34 автоматических сценария и реальные кадры движка через Mesa EGL. Новая сборка APK и нативные браузерные жесты ожидают GitHub Actions. На телефоне важны повторные проверки: ходьба вместе с обзором и ударом, прокрутка рюкзака по ячейкам, стрельба и автоматическая перезарядка, бой с боссом, плавность при исследовании новых участков.

Осталось подтвердить ощущения и производительность на физических устройствах. Текущий визуальный вариант ещё не одобрен пользователем. Не называть его согласованным, окончательным или гарантированно работающим без тормозов на всех телефонах.

Дальнейшее развитие: полноценный поиск пути врагов, совместные награды и постоянные профили гостей в LAN, интернет-комнаты, API модов с новыми моделями, больше биомов и содержания, NPC, транспорт. Сохранения 0.2 совместимы; пакет Android прежний.
