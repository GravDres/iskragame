# Искра: Дикий рубеж — Android-альфа 0.3

Оригинальная 3D-песочница от первого лица. Собственный небольшой движок на JavaScript и WebGL 1; Android-приложение использует системный WebView как графическую среду. Unity, Godot, Three.js и другие игровые движки не используются.

Версия 0.3 переделывает управление, инвентарь, рендерер, оружие и боссов после теста на телефоне. Изменения описаны в CHANGELOG.md, локальные замеры — в PERFORMANCE.md. APK новой версии собирается через GitHub Actions; локально Android SDK отсутствует.

## Посмотреть сейчас

Кадры из настоящего движка: `preview/preview-rifle.png`, `preview/preview-frost.png`, `preview/preview-bosses.png`. Это отрисовка мира без меню и сенсорного интерфейса.

Для быстрой пробы на компьютере скачай и открой `play-preview.html` в браузере с WebGL. Все файлы встроены, установка не нужна. На телефоне открытие локального HTML зависит от браузера и файлового менеджера; основной формат для Android — APK. Для разработки используй файлы в `game`, затем выполни `python3 tools/build-preview.py`.

## Самый простой способ получить APK через GitHub

1. Создай пустой репозиторий на GitHub. Можно приватный.
2. Распакуй архив. Загрузи **содержимое папки проекта в корень репозитория**, включая скрытую папку `.github`. В корне должны оказаться `README.md`, `game`, `android`, `tests`, `mods` и `.github`.
3. Если пользуешься загрузкой файлов через браузер, обязательно проверь наличие `.github/workflows/build-apk.yml`. При необходимости создай этот файл через **Add file → Create new file**, скопировав его содержимое из проекта. ZIP целиком загружать в репозиторий не нужно.
4. Открой **Actions → Build Iskra APK**. Сборка запускается при загрузке в `main`/`master`; её также можно запустить через **Run workflow**. Если GitHub попросит включить Actions, включи их.
5. Когда закончится шаг сборки, внизу страницы запуска появится **Artifacts → Iskra-Android-APK**. Скачай архив, распакуй `Iskra-0.3.0.apk` и установи на телефон.
6. Артефакт APK загружается **до** проверки браузерного интерфейса. Если именно последующая визуальная проверка завершится ошибкой, уже собранный APK всё равно доступен. В **Iskra-Preview** будут доступные скриншоты проверки.

Для установки вне Google Play Android может попросить разрешить установку из используемого файлового менеджера или браузера. APK подписывается локальным ключом альфы. Workflow сохраняет этот ключ в GitHub Actions Cache для следующих сборок. Если кэш удалится, новый ключ будет отличаться и обновление поверх старой установки может не установиться. Удаление приложения удаляет его локальные миры. Для постоянных обновлений сохрани один ключ и настрой его в GitHub Secrets; не публикуй приватный ключ.

## Что реализовано в исходниках

- Одна процедурная карта 768 × 768 × 72 блока с постоянным seed, четырьмя биомами, пещерами, рудами, деревьями, руинами и небольшим заброшенным домом. Карта загружается участками вокруг игрока.
- Режимы **Выживание**, **Творчество**, **Охота**. География совпадает, сохранения режимов отдельные.
- Круглый аналоговый джойстик с фиксированным или плавающим центром, зоной нечувствительности и движением относительно камеры. Независимые касания позволяют одновременно идти, смотреть и атаковать. Чувствительность учитывает экран. Бег при полном наклоне вперёд можно отключить.
- Одна контекстная кнопка: копать / ударить / выстрелить / колдовать / поставить блок. Рядом только прыжок. Рюкзак прокручивается пальцем, имеет категории и цветные иллюстрации предметов. Есть рецепты, здоровье, сытость, мана, еда и зелья.
- **26 доступных строительных блоков**: земля, камень, дерево, песок, доски, кирпич, стекло, фонарь, лёд, булыжник, глина, мрамор, обсидиан, медный блок, мшистый камень, красный песчаник, цветущий дёрн, тёмные доски, ледяной кирпич, светящийся камень, дёрн, листва, снег, базальт, кристальный блок, коренная порода. Набор мира также включает воду и руды. Коренная порода предназначена преимущественно для творчества.
- Пистолет, автомат, дробовик, ПП, снайперская винтовка, лук, арбалет, граната, меч, копьё, тяжёлый молот, ракетомёт, огненный, ледяной и грозовой посохи. У огнестрельного оружия есть магазины и перезарядка. Стрелы и гранаты используют отдельные боеприпасы и летят по дуге. Патроны и мана расходуются. Огонь поджигает, лёд замедляет, ракеты наносят урон по площади. Кирка и топор также могут ударить противника.
- **10 обычных видов врагов**: Моховый сгустень, Ночной рыскач, Рудокамень, Искронос, Костяной дозорный, Пещерный иглоног, Инеевый рыскач, Бронзоспин, Сумрачник, Листоскор. Добыча автоматически попадает в рюкзак победителя в одиночной игре.
- **7 оригинальных боссов**: Арвель, Кхарос, Нивея, Тир’Вэл, Орук, Ноктар, Элион. Уровни призыва — 2 / 3 / 5 / 7 / 9 / 11 / 14. Для следующего нужна предыдущая победа и своя созданная реликвия. Она расходуется только при успешном призыве. Корни замедляют, ледяная волна замораживает, разлом притягивает, скарабей ускоряется; есть залпы и помощники. Перед ударами по площади появляется кольцо предупреждения. В охоте и творчестве ограничения прогрессии сняты.
- Уровни 1–20, опыт за победы, новые области и добычу природных ресурсов. Уровень, опыт, открытые области, реликвии, победы и состояние магазинов сохраняются.
- Автосохранение каждые 25 игровых секунд, ручное сохранение в паузе, сохранение при уходе из приложения, возвращение в лагерь после смерти.
- Полноэкранная Android-оболочка, горизонтальная ориентация, импорт JSON-модов через системный выбор файла.
- Настройки дальности, разрешения отрисовки **360p / 540p / 720p / 1080p / авто**, ограничения кадров, угла обзора, чувствительности, звука, инверсии и FPS. Пропорции экрана сохраняются; разрешение системы Android не изменяется.
- Размеры джойстика, кнопок и интерфейса, прозрачность, джойстик справа, перетаскивание элементов управления и сохранение раскладки в процентах от экрана.

## Как играть

Начни с **Творчества**, чтобы освоиться, или **Охоты**, чтобы сразу испытать весь арсенал. В **Выживании** есть начальные инструменты, пистолет, меч, два посоха, материалы, еда и 100 патронов. Автомат, дробовик и другие предметы создаются из ресурсов.

Слева — круглый джойстик, справа — свободная область обзора, прыжок и одна большая кнопка. Её действие меняется вместе с выбранным предметом. Кирку или топор удерживай для добычи. Меч бьёт, посох колдует, оружие стреляет и автоматически перезаряжается при пустом магазине. Выбери блок и нажми «Поставить», чтобы строить. Сумка сверху открывает предметы, рецепты и боссов. Нажатие на еду или зелье в рюкзаке использует предмет.

Дважды нажми прыжок в творчестве для полёта. Удерживай прыжок для подъёма; для снижения потяни палец вниз по этой же кнопке.

На компьютере: WASD, мышь, Space, Shift, 1–8, R для перезарядки, Q/E для стихий, B для рюкзака, Esc для паузы, F для еды, H для зелья. Первый щелчок по миру захватывает мышь.

## Игра с друзьями

В Android-оболочке написан экспериментальный LAN-транспорт: TCP, порт **24871**, хозяин и до трёх гостей. Это ещё нужно проверить на двух физических телефонах.

1. Подключите телефоны к одной Wi-Fi сети без изоляции клиентов. Интернет не требуется.
2. Хозяин начинает игру и открывает **Пауза → Играть с друзьями → Создать комнату**.
3. Друг начинает свой мир, открывает то же меню и вводит IPv4-адрес хозяина.
4. Хозяин рассчитывает противников, снаряды, изменения мира и сохраняет карту. Гости отправляют положение, строительство и боевые действия.

Хозяин должен оставаться в игре: открытие меню останавливает его симуляцию. В этой альфе уровень и победы общие, призыв проверяет реликвию хозяина; награды за общих врагов получает хозяин; синхронизация инвентарей и постоянных профилей гостей ещё не реализована. Интернет-серверов, матчмейкинга, чата и переподключения с восстановлением гостевого профиля пока нет. В обычном браузере Android LAN-мост недоступен.

## Моды

Открой **Моды → Загрузить JSON-мод**. Пример: `mods/elemental-arsenal.json`.

Моды формата 1 изменяют существующее оружие. Поддерживаются имя, урон, темп, дальность, расход маны, скорость снаряда, разброс, количество дробинок, поджог и заморозка. Все значения проверяются до применения. Исполняемые скрипты не принимаются. Ограничения — до 150 КБ на файл, до 10 модов. Пока нет API новых моделей, биомов, текстур и скриптовых механик.

## Локальная сборка

Нужны Linux, Java 21, Python 3 и доступ к загрузке Android-инструментов:

```bash
python3 android/bootstrap.py
bash android/build.sh
```

Получишь `dist/Iskra-0.3.0.apk`. Gradle не требуется: Стандартный javac из JDK компилирует Java с --release 8, D8 создаёт DEX, AAPT2 упаковывает ресурсы и игровой код, zipalign и apksigner выравнивают и подписывают APK.

При установленном Android SDK можно создать `.toolchain/platform` и `.toolchain/buildtools` как ссылки на `platforms/android-35` и `build-tools/35.0.0`, используя полный JDK 21 с javac. Workflow устанавливает SDK и передаёт абсолютные пути через `ISKRA_ANDROID_JAR` и `ISKRA_BUILD_TOOLS`; локально используются пути `.toolchain/platform/android.jar` и `.toolchain/buildtools`. ECJ не требуется.

Просмотр версии для компьютера:

```bash
python3 -m http.server 8000 --directory game
```

Открой `http://localhost:8000`. Поддержку модов можно проверить через выбор локального JSON-файла; Wi-Fi-мост работает только в APK.
